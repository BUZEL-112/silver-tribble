Production Design Decisions

System Architecture and Engineering Trade-Offs

01. Remotion Motion Engine

Programmatic Motion Graphics vs FFmpeg Scripting

Replaced rigid FFmpeg shell scripting with Remotion React 18. CSS layouts, spring physics transitions, and procedural cyber grid backgrounds are compiled deterministically into frame buffers using headless Chromium.

02. Multi-Model Routing

Zero-Downtime Provider Fallback Chains

Unified model registry allows abstract pipeline roles to route with automatic fallback. If OpenAI rate limits or DeepSeek times out, the pipeline seamlessly downgrades to Gemini 2.5 Flash without manual intervention.

03. Forced Word Alignment

Whisper Audio Synchronization vs Linear Pacing

Avoids naive word pacing approximations. Faster-Whisper performs forced alignment between spoken WAV audio and script tokens, producing exact millisecond boundaries for kinetic subtitle rendering.

04. Sub-Cent Cost Model

Budget Guardrails and Spend Optimization

Employs local FastEmbed ONNX models for article clustering to eliminate embedding API costs. Fine-grained cost guardrail service enforces hard budget stops before dispatching external calls.

05. Workflow Resilience

Prefect 3.x Checkpointed Task Graphs

Decoupled state machines track each job through Ingestion, Clustering, Scripting, Audio, and Rendering. Transient media fetch or TTS network errors trigger automated retries with exponential backoff.

06. Zero-Key Local Sandbox

Single-Command Reviewer Evaluation

Engineered an offline sandbox mode (python -m src.cli demo) using synthetic fixtures and deterministic fallbacks. Reviewers can test the complete pipeline end-to-end without provisioning API keys.
