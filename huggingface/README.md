# Autonomous AI News to Video Production Engine - Static Showcase

This static Space hosts the interactive portfolio showcase for the Modular AI Video Production Platform.
It communicates with the serverless Google Cloud Run backend API via HTTPS REST endpoints and client-side bearer tokens stored in localStorage.

## Features

- Remotion React Canvas Player and Kinetic Caption Sync
- Autonomous Pipeline Orchestration Telemetry
- Multi-Tab Intermediate Artifact Inspector (Story Clusters, Beat Sheets, Whisper Timestamps, YouTube SEO, Cost Audits)
- Zero-cost static delivery on global CDN

## Configuration

Click **Cloud Settings** in the top navigation bar to configure:
- `Backend API Base URL`: Your Google Cloud Run service URL
- `API Bearer Token`: Pre-shared token matching `API_AUTH_TOKEN`
